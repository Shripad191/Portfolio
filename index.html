Serverless URL Shortener

A bit.ly-style shortener that runs entirely on managed AWS services and costs nothing within the Free Tier. POST a long URL to /shorten, get a short code back; GET /{code} returns a 302 to the original.

  • Two single-purpose Lambdas (Python 3.12): one shortens, one redirects
  • DynamoDB conditional writes prevent short-code collisions
  • Each function gets its own least-privilege IAM role
  • One-command deploy.sh and cleanup.sh with AWS CLI v2

About

I like the part of software most people never see: the network layout, the permissions, the scripts that turn an empty AWS account into a running service and back again.

My projects lean toward architectures you can defend in a design review. Private subnets for anything that doesn't need to be public. One IAM role per function. Short-lived infrastructure that tears down cleanly so nothing is left running and billing.

I also have a background in data and machine learning, which helps when the workloads I'm hosting are data pipelines or ML models.

Security firstLeast-privilege IAM, tiered security groups, no hard-coded secrets.
